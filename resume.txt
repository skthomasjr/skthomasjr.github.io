Unpaid independent open-source side project; built during evenings and weekends.

Designed and built Witwave, a cloud-native autonomous agent framework for AI agent teams. The project treats AI agents as managed software participants with durable identity, backend choice, schedules, triggers, memory, observability, MCP tool access, shared workspaces, and human-governed escalation.
